# 2026-10-16

## TypeScript 7.0.2 升级方案

解决 TS7 + tsup/rollup-plugin-dts DTS 构建失败：TS7 不再暴露旧 compiler API，tsup 8 内置 rollup-plugin-dts 直接报 `useCaseSensitiveFileNames`；tsup 9 对 rollup-plugin-dts 有提示但自身 DTS 路径仍会调用 `typescript@7.parseJsonConfigFileContent`。最终方案：升级 `tsup` 到 9.0.0，但关闭 tsup 的 DTS 管线，`tsup` 只构建 JS，三包 build 脚本追加 `tsc --emitDeclarationOnly` 单独生成 `.d.ts`；`tsconfig.base.json` 明确 `types: ["node"]`；core 的 declaration build 只 include `src/index.ts`；tsup config 关闭 `clean` 以避开本环境 safe-delete 对 dist 删除的拦截；Vitest 5 三包配置独立 `fsModuleCachePath` 避开旧 `node_modules/.vitest-cache` 批量删除。完整验证 `pnpm verify` 已通过：lint/build/typecheck/test 全绿（core 371、dashboard 389、cli 84）。
