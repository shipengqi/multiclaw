## Human Checkpoint（分层 Review Gate，方案 B）
- 用户认可「设计类 agent 完成后暂停给用户 review，开发类走自动化 review」的分层思路。
- core：`config.checkpoints: { afterAgents: string[]; label?: string }[]` + `CheckpointPolicy/CheckpointInfo/CheckpointResponse/CheckpointHandler` 类型。Orchestrator 在 stage 循环里 stage:complete 后检查 checkpoint，命中则 `await onCheckpoint(info, signal)` 暂停；response action = `continue`/`cancel`/`modify`（`modify` 把 instruction 追加进 requirement 后续 stage）。
- 无 handler 时跳过 checkpoint；signal.aborted 时 fail-cancel。
- TUI：`handleCheckpoint` 用 `checkpointResolveRef` 存 resolve，`/continue` `/modify <text>` `/cancel` 在 checkpoint pending 时优先处理；直接输入文本等价 `/modify`。命令可用性：`/continue` 始终可用，`/modify` 常驻。
- 新增 core 回归测试 6 个 + dashboard 集成测试 2 个（App.checkpoint.test.tsx 新建）；原有 Orchestrator.run 109/109、commands 54/54、history 9/9 全绿。
- 顺手改：history `c` 键在设 continuationRef 同时 `dispatch view:open`，让用户按 c 后直接看到历史上下文再打字。
