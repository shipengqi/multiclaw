# @multiclawcli/core

[![npm](https://img.shields.io/npm/v/@multiclawcli/core)](https://www.npmjs.com/package/@multiclawcli/core)
[![GitHub](https://img.shields.io/badge/GitHub-shipengqi%2Fmulticlaw-blue?logo=github)](https://github.com/shipengqi/multiclaw)

Core runtime for [multiclaw](https://github.com/shipengqi/multiclaw) — the multi-agent orchestration CLI.

This package provides the agent runner, orchestrator, event bus, and runtime abstractions used internally by the `multiclaw` CLI. It is not intended for direct use; install [`multiclaw`](https://www.npmjs.com/package/multiclaw) instead.

## Documentation

Full documentation is available in the [main repository](https://github.com/shipengqi/multiclaw).
